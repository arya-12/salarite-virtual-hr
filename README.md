# Salarite Virtual HR

A Virtual HR and ATS task management platform built for the Salarite assignment.

## Features

- Employr can assign tasks to Virtual HR
- View all assigned tasks
- Updt task status
- Trak completed tasks
- Schedule candidate interviews
- Interview modes: Video, Voice, Chat
- Employer dashboard
- Automatic dashboard refresh
- FastAPI REST API
- MySQL database integration

## Tech Stack

### Backend
- Python
- FastAPI
- SQLAlchemy
- MySQL
- PyMySQL
- Uvicorn

### Frontend
- Next.js
- TypeScript
- Tailwind CSS
